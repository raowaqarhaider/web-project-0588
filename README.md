# GAMEVERSE – Gaming Website

## Project Overview

GAMEVERSE is a multi-page gaming website created as part of the Web Technologies Assignment 1 and 2.

The website is designed for gaming enthusiasts who are interested in gaming, technology, gaming setups, esports and gaming communities.

The main purpose of this project is to practise HTML, CSS and basic JavaScript concepts by creating a responsive and attractive website.

## Website Theme

Theme: Gaming Website

Website Name: GAMEVERSE

Tagline: Play Beyond Limits. Discover Your Next Adventure.

## Technologies Used

- HTML5 – To create the structure of web pages.
- CSS3 – To design and style the website.
- JavaScript – To perform basic DOM operations and form validation.
- Visual Studio Code – For writing and editing code.
- Git and GitHub – For version control and project submission.

## Website Pages

This website contains six pages:

| No. | Page Name | File Name | Description |
|---|---|---|---|
| 1 | Home | index.html | Introduction to GAMEVERSE |
| 2 | Media | media.html | Gaming images, videos, audio and information |
| 3 | Register | register.html | Registration form for users |
| 4 | Services | services.html | Gaming services and support |
| 5 | Portfolio | portfolio.html | Gallery of gaming setups and moments |
| 6 | Contact | contact.html | About section and contact form |
